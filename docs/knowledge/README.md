## 核心信条

1. **不诊断、不替代、有行动**——产品级约束，详见 [安全红线](./06-safety.md)。
2. **确定性规则优先于模型判断**——能用意志力确定的事，不要交给概率。
3. **每次模型改动都必须有评测数据支撑**——没有数字的优化是玄学。
4. **危机路径绝不调用 LLM**——这是 P0 红线，任何重构都不能破坏。
5. **文档与代码同源**——改代码就改文档，PR 模板里有对应自检项。

## 给 AI 助手的用法

在 Qoder 中可以直接引用本目录：

```
参考 docs/knowledge/02-architecture-map.md 说明请求链路
参考 docs/knowledge/06-safety.md 校验本次改动是否触碰红线
```

项目级技能位于 `.qoder/skills/`，会自动触发；规则位于 `.qoder/rules/`，对所有会话生效。
