## 核心概念

VIA（Values in Action）优势分类系统由马丁·塞利格曼与米哈里·契克森米哈赖提出，
把人类优势分为 6 大类 24 项：

| 类别 | 代表优势 |
| --- | --- |
| 智慧与认知 | 创造、批判、好奇、热爱学习、睿智 |
| 勇气 | 勇敢、执着、诚实、勇气 |
| 人际 | 亲和、爱心、社交能力、团队合作 |
| 仁慈 | 善良、慷慨、忠诚、谦逊 |
| 正义 | 勇气、正直、公民意识 |
| 生命力 | 热爱生命、热情、自律、谨慎、敬业、感恩、乐观 |

## 核心主张

传统的性格测评多以"问题"为中心（你有什么缺陷），VIA 以"优势"为中心
（你在这里天然有优势）。这个转向有实际意义：

- 优势导向的干预在动机维持上优于缺陷导向
- 让一个人识别并运用自己的优势，**同时不需要假装弱点不存在**
- 优势与"优势盲点"（overused strength）结合使用效果最好：
  例如"执着"是优势，但在需要灵活变通时会变成盲点

## 测评方法

标准 VIA 问卷为 48 题（每类 8 题），本产品采用简化的 30 题自适应版本：
每题 5 级李克特计分，按区分度动态选题。

## 关键注意点

1. **优势不是能力上限**。VIA 测的是"你天生擅长且享受"，不是"你只能做这个"。
2. **优势盲点比优势本身更重要**。很多人知道自己的优势，但不知道它在什么情况下会变成负担。
3. **不要用于评估岗位胜任力**。VIA 与大五人格中的尽责性只有中等相关，
   不能替代岗位胜任力模型。

## 应用到微行动

识别出优势后，把微行动设计成"调用优势"而非"克服弱点"：
- 优势是"共情" → 微行动是"主动问同事今天怎么样"，而不是"克服社交焦虑"
- 优势是"分析" → 微行动是"把困扰拆成三块列出来"，而不是"别想太多"
